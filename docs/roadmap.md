# Roadmap

Ideas, roughly in order. Nothing here is built yet.

## Soon

- **Position setting**: pick any corner, and which monitor.
- **"Today" list**: click the "Next up" text to see the whole day.
- **Skip today**: one click to silence everything for the rest of the day (sick day, holiday).
- **Custom notes** in the add form (the `note` field already works, it just has no input yet).
- **Edit a reminder** in place instead of delete and re-add.

## Later

- **Break nudges**: "You've been sitting for an hour, stretch?" using GNOME's idle time.
- **Water tracker**: tap Mochi to log a glass, Mochi gets happier.
- **Calendar**: show the next meeting from GNOME Calendar / Evolution Data Server.
- **Pomodoro**: a focus timer in the pill.
- **More moods**: worried (overdue), celebrating (all done for the day).
- **Translations** with gettext.

## Maybe

- Publish on extensions.gnome.org (needs a proper UUID like `mochi-buddy@yourname.github.io`).
- Little sounds of Mochi's own.
